# body-brain eval: 내 실제 질문 추가하는 법

1. 실제로 궁금했던 질문을 `questions.yaml` 맨 아래에 새 항목으로 붙이고, 번호는 마지막 번호 다음(q31부터)으로 씁니다. 기존 번호는 재사용하지 않아요.
2. `ko`에는 평소 치는 말투 그대로, `en`에는 같은 뜻의 자연스러운 영어를 쓰고, `category`·`expected_route`는 기존 항목을 보고 고릅니다.
3. `profile_fixture`는 `profiles.yaml`의 가상 인물 중 가장 가까운 사람을 고릅니다. 실제 약·질환 정보는 이 폴더에 넣지 않아요.
4. `must`·`must_not`은 "출처 1개 이상", "제품 이름 없음"처럼 예/아니오로 판정되게 쓰고, 자동 검사는 `[rule]`, AI 채점은 `[judge]`를 앞에 붙입니다.
5. 새 질문은 기본 `split: tune`으로 넣고, 3개 모일 때마다 1개를 `holdout`으로 돌려 비율(2:1)을 유지합니다. 한 번 holdout이 된 질문은 다시 tune으로 옮기지 않아요.
